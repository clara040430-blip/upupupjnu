올라가조 웹 통합 v2.5 — CCS ADC v2.3 디지털 필터 동작 시뮬레이션

[목적]
개발 현황 안내 탭 추가가 아니라 실제 ADC 처리 알고리즘을 웹에서 검증하는 기능 추가.
원래 웹사이트의 4개 보드, 보호 시뮬레이션, 그래프, 냉각, 통신 브리지 유지.

[웹사이트 이용]
웹을 실행하면 상단의 'ADC 필터 실험'을 누르거나 아래로 스크롤.
- 9개 ADC 채널 중 하나 선택
- 정상 일정 신호 / 입력값 급변 / 순간 펄스 중 선택
- 노이즈 크기를 슬라이더로 바꾸고 원시값(주황)과 EMA(파랑) 비교
- 전 구간(0~500ms), 확대 구간(135~195ms) 비교
- 초록색 점: 펌웨어 규격에 맞게 100ms마다 계산한 스냅샷
- 옵션: α 계수를 웹에서만 시험(실제 CCS 펌웨어 설정은 그대로)

[펌웨어 연관 기준]
F28388D CCS ADC v2.3의 1ms(1kHz) 샘플, 전압/전류 EMA α=0.2,
온도 EMA α=0.05, 100ms 스냅샷, 9개 ADC 매핑을 반영.
첫 측정에서는 EMA를 측정값 그대로 시작해 가짜 시동 램프 없음.
9채널 모두 ADC 핀 전압(V)으로 비교; 전류 A/온도 °C 환산 검증은 아직 불가.
시연 그래프는 실제 MCU 센싱 결과가 아니라 모델이 만든 1ms 가상 시험 데이터.
기존 자동 데모의 1Hz 패킷에는 1ms 측정 이력이 없으므로 필터 검증에 재활용하지 않음.

[설치: 기존 작업을 지키는 방법]
1. C:\Users\ueuin\Documents\PV_CLLC_Project\web 폴더를 먼저 백업.
2. 압축 해제 후 ZIP 안의 web 파일/폴더 내용을 기존 web 폴더에 병합.
   같은 이름 파일은 교체. 기존 .git / node_modules는 삭제하지 않음.
3. VS Code에서 기존 web 폴더를 열고 아래 명령을 실행.
   npm.cmd install
   npm.cmd test
   npm.cmd run build
   npm.cmd run dev
4. 브라우저에서 화면 상단 'ADC 필터 실험' 클릭.
5. GitHub 공개를 원한다면 추후 git status / add / commit / push 후 Pages 배포 확인.
