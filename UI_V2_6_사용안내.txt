올라가조 PV-CLLC 통합 웹 UI/UX v2.6
====================================

이 버전의 목적
- 기존 v2.5의 계산식/ADC 모델/보호엔진/냉각모델/PC 브리지/데이터 프로토콜은 그대로 유지
- 매우 긴 단일 페이지를 좌측 메뉴 + 화면 전환 방식으로 개편
- 주요 실험은 설정 → 결과 → 설정으로 돌아가기 흐름으로 전환
- 보드별 선택과 시험값/이벤트 기록은 메뉴 이동에도 유지 (페이지는 숨기지만 언마운트하지 않음)

메뉴
- 홈: 시험 선택 카드
- 데이터 연결: 자동 시연/PC 브리지/수동 입력 모드 선택
- 보드 현황: BOARD-01~04 선택
- 수동 센서 시험: 9채널 값·전류 극성 입력 → 화면 상단 '시험 시작' → '결과 확인'
- 보호 기능 시험: 시험 임계값 변경 또는 '센서값 설정' → 보호 상태/이벤트/복귀 확인
- ADC 필터 실험: 채널·신호·노이즈·EMA 계수 설정 → 결과 확인
- 냉각 계산: 주변 온도·시정수·목표 온도 설정 → 결과 확인
- 센싱·전력 분석: 9채널 환산 결과·세부 ADC 정보
- 실시간 그래프: 시간 이력·CSV

주의
- 상단의 '시험 시작/중지' 버튼은 선택한 데이터 모드에 작동하며, 브리지는 자체 수신을 사용함.
- MCU의 실측 데이터 수신과 실제 PWM 제어는 아직 구현된 것이 아님.
- 필터 실험은 CCS v2.3 식을 가상 데이터에 적용한 단위 시험임.
- 메인 홈의 1ms/100ms는 펌웨어 설계 기준이며, 웹 자동 데모는 1초마다 갱신됨.

적용 방법
1. 현재 C:\Users\ueuin\Documents\PV_CLLC_Project\web 폴더를 먼저 복사해 web_backup_v25로 백업.
2. ZIP 내용 중 파일과 폴더를 기존 web에 복사 및 덮어쓰기. .git/node_modules는 건드리지 않음.
3. VS Code 터미널에서 npm.cmd run build, npm.cmd run dev
4. 로컬 사이트에서 4개 보드/보호/ADC 필터/냉각/통신 화면을 확인한 후 GitHub로 배포.
